# 백엔드 연동 따라하기 (처음 하시는 분용)

이 문서는 "일단 순서대로 따라 하면 프론트-백엔드가 연결된다"를 목표로 만든 실습형 가이드입니다. API 하나하나의 자세한 요청/응답 형식은 같은 폴더의 **`백엔드_연동_가이드.md`**에 정리되어 있으니, 이 문서를 진행하다가 "이 API는 정확히 어떻게 만들어야 하지?" 싶으면 그 문서를 같이 펴놓고 참고하세요.

---

## 0단계. 준비물

- Node.js (이미 설치되어 있다면 패스)
- 이 저장소(`temp-react` 폴더)를 통째로 받은 상태
- 여러분이 만들고 있는(또는 만들) 백엔드 서버

---

## 1단계. 프론트엔드 먼저 켜보기 (백엔드 없이)

터미널에서 `temp-react` 폴더로 들어가서:

```bash
npm install
npm start
```

브라우저에 `http://localhost:3000`이 자동으로 뜨면 성공입니다. 백엔드가 없어도 이 상태로 화면 이동은 전부 됩니다. 다만 데이터가 필요한 부분(목록, 프로필 등)은 빈 화면이거나 에러 문구가 뜨는 게 **정상**입니다 — 아직 백엔드에 연결 안 했으니까요.

> ⚠️ 이 단계에서 `cross-env: not found` 같은 에러가 뜨면 → `npm install`을 안 하고 바로 `npm start`를 실행했을 가능성이 높습니다. `npm install`부터 다시 하세요.

---

## 2단계. `.env` 파일 만들기

`temp-react` 폴더 안의 `.env.example` 파일을 복사해서 이름을 `.env`로 바꾸세요. (이미 `.env`가 있다면 이 단계는 건너뛰어도 됩니다.)

```bash
cp .env.example .env
```

`.env` 파일을 열어보면 이런 항목들이 있습니다. **지금 당장 다 채울 필요는 없고, 아래 단계마다 하나씩 채우면 됩니다.**

```
REACT_APP_API_BASE_URL=
REACT_APP_KAKAO_MAP_KEY=
REACT_APP_KAKAO_CLIENT_ID=
REACT_APP_KAKAO_REDIRECT_URI=
REACT_APP_ADMIN_PASSWORD=
```

**중요**: `.env`를 수정한 뒤에는 **`npm start`를 껐다가(Ctrl+C) 다시 켜야** 반영됩니다. 켜져 있는 상태에서 `.env`만 고치면 브라우저에는 아무 변화가 없습니다 — 자주 헷갈리는 부분이니 꼭 기억해두세요.

---

## 3단계. 백엔드 서버 주소 연결하기

여러분의 백엔드 서버를 로컬에서 실행시켜두세요 (예: `http://localhost:8080`에서 떠 있다고 가정).

`.env`에 이렇게 채웁니다:

```
REACT_APP_API_BASE_URL=http://localhost:8080
```

`npm start`를 재시작하면, 이제 프론트가 보내는 모든 API 요청이 `http://localhost:8080/api/...`로 나갑니다.

이 시점에서 브라우저 화면들을 눌러보면 대부분 이런 에러가 뜰 거예요:

```
서버 응답을 해석할 수 없습니다. API 서버 연결(REACT_APP_API_BASE_URL)을 확인해주세요. (/api/stores)
```

또는

```
요청에 실패했습니다. (404)
```

**둘 다 정상입니다.** 주소는 맞게 연결됐는데, 그 경로(`/api/stores` 등)를 처리하는 코드가 아직 백엔드에 없다는 뜻이에요. 이제 하나씩 만들면 됩니다.

---

## 4단계. 백엔드 API를 하나씩 만들면서 확인하기

**한 번에 다 만들 필요 없습니다.** 아래 순서대로 하나 만들고, 프론트에서 눌러보고, 되는 거 확인하고, 다음 걸로 넘어가세요. (전체 API 목록/형식은 `백엔드_연동_가이드.md`의 "7. API 명세" 참고)

### 추천 순서

1. **`GET /api/stores`** — 매장 목록. 이것부터 만드는 걸 추천합니다. 응답 형식이 제일 단순하고, 홈 화면(지도 또는 "목록" 탭)에서 바로 눈으로 확인할 수 있어요.
   - 확인 방법: `npm start` 후 홈 화면 접속 → 상단 탭에서 "📋 목록" 클릭 → 매장이 카드로 뜨면 성공
2. **`POST /api/auth/kakao`** — 로그인. 5단계(카카오 로그인 설정)를 먼저 끝내야 테스트할 수 있습니다.
3. **`GET /api/users/me`**, **`GET /api/users/me/stats`** — 마이페이지 프로필/통계
4. **`GET /api/stores/:id/lunchbox`**, **`POST /api/applications`**, **`GET /api/applications/me`** — 도시락 신청
5. **`GET /api/stores/mine`**, **`POST /api/food-registrations`** 등 — 식품 등록 (소속 인증부터 먼저 되어야 테스트 가능)
6. 나머지는 순서 상관없이 필요한 순서대로

각 API를 만들 때마다:
- 정확한 요청 방식(GET/POST/PATCH/DELETE), 경로, body 형식은 `백엔드_연동_가이드.md`를 그대로 따라 하세요.
- 프론트 코드는 **전혀 수정할 필요 없습니다.** 백엔드가 정해진 형식으로 응답만 주면 화면에 바로 반영됩니다.

---

## 5단계. 카카오 로그인 연결하기

로그인 화면에서 "카카오 로그인" 버튼을 누르면 원래 카카오 로그인 창이 떠야 합니다. 이걸 켜려면:

1. https://developers.kakao.com 접속 → 로그인 → "내 애플리케이션" → 애플리케이션 추가 (이미 만들어져 있다면 그거 사용)
2. "앱 키" 메뉴에서 **REST API 키**를 복사
3. "카카오 로그인" 메뉴에서 활성화 ON
4. "Redirect URI" 항목에 `http://localhost:3000` 등록 (배포 후에는 실제 배포 주소도 추가로 등록해야 함)
5. `.env`에 채워 넣기:
   ```
   REACT_APP_KAKAO_CLIENT_ID=여기에_REST_API_키
   REACT_APP_KAKAO_REDIRECT_URI=http://localhost:3000
   ```
6. `npm start` 재시작

이제 "카카오 로그인" 버튼을 누르면 실제 카카오 로그인 화면으로 이동합니다. 로그인하면 `http://localhost:3000/?code=...`로 돌아오고, 프론트가 자동으로 그 코드를 백엔드의 `POST /api/auth/kakao`로 보냅니다.

> ⚠️ 이 시점에 **"요청에 실패했습니다 (404)"**가 뜬다면 → `POST /api/auth/kakao`가 아직 백엔드에 구현되어 있지 않다는 뜻입니다. 3~4단계로 돌아가서 이 API부터 만드세요. `.env`의 `REACT_APP_API_BASE_URL`이 백엔드 서버를 제대로 가리키고 있는지도 다시 확인하세요.

> 참고: `REACT_APP_KAKAO_CLIENT_ID`가 비어있으면, "카카오 로그인" 버튼은 그냥 홈 화면으로 바로 이동하는 임시 동작을 합니다. 백엔드 로그인 API가 아직 준비 안 됐을 때 프론트의 다른 화면들을 테스트하고 싶다면, 일부러 이 값을 비워두거나 주석 처리해서 이 임시 동작을 활용하셔도 됩니다.

---

## 6단계. 카카오맵 연결하기 (지도가 안 보일 때)

홈 화면에 "지도를 불러오지 못했습니다" 문구만 보인다면:

1. https://developers.kakao.com → 같은 애플리케이션 → "앱 키"에서 **JavaScript 키** 복사
2. "플랫폼 > Web" 에 `http://localhost:3000` 등록
3. "제품 설정 > 카카오맵" 활성화
4. `.env`:
   ```
   REACT_APP_KAKAO_MAP_KEY=여기에_JavaScript_키
   ```
5. `npm start` 재시작

---

## 7단계. 관리자 페이지 (`/admin`) 비밀번호

`http://localhost:3000/admin`으로 들어가면 소속 인증 승인용 관리자 화면이 있습니다.

- 지금은 `.env`의 `REACT_APP_ADMIN_PASSWORD` 값으로 로그인합니다(백엔드 없이 프론트에서 바로 비교). 원하는 비밀번호로 바꿔도 됩니다.
- 나중에 백엔드에 `POST /api/admin/login`을 진짜로 구현하면, `.env`에서 이 줄을 지우세요 — 그러면 자동으로 진짜 서버 로그인 방식으로 전환됩니다.

## 자주 겪는 에러 모음

| 증상 | 원인 | 해결 |
|---|---|---|
| `sh: cross-env: not found` | `npm install`을 안 하고 `npm start`부터 실행함 | `npm install` 먼저 실행 |
| `.env`를 고쳤는데 화면이 그대로임 | `.env`는 서버 켤 때 딱 1번만 읽음 | `npm start`를 껐다 다시 켜기 |
| "서버 응답을 해석할 수 없습니다..." | `REACT_APP_API_BASE_URL`이 비어있거나, 그 주소에 백엔드가 안 켜져 있음 | `.env` 주소 확인 + 백엔드 서버 실행 확인 |
| "요청에 실패했습니다 (404)" | 주소는 맞는데 그 API 경로가 백엔드에 아직 없음 | 해당 API를 백엔드에 구현 (`백엔드_연동_가이드.md` 참고) |
| 지도에 "불러오지 못했습니다" | `REACT_APP_KAKAO_MAP_KEY` 미설정 | 6단계 참고 |
| 카카오 로그인 버튼이 그냥 홈으로 감 | `REACT_APP_KAKAO_CLIENT_ID` 미설정 (의도된 임시 동작) | 5단계 참고, 필요 없으면 그냥 둬도 됨 |

---

## 핵심 요약

1. `npm install` → `npm start`로 프론트만 먼저 켜본다
2. `.env` 만들고 `REACT_APP_API_BASE_URL`을 내 백엔드 주소로 채운다 (바꿀 때마다 서버 재시작!)
3. `백엔드_연동_가이드.md`의 API 목록을 위에서부터 하나씩 구현하면서, 그때그때 프론트 화면을 눌러 확인한다
4. 프론트 코드는 건드릴 필요 없음 — 백엔드가 정해진 형식대로 응답만 주면 자동으로 화면에 반영됨
